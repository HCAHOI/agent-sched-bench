Carrier audit 可逐行追溯

  • row sidecar 共 1,792 行，其中 119 行标记为 pip command。
  • 15 个 Jaccard non-exact carriers 全部记录 normalized signature、Current/canonical/Jaccard hard prediction、label 与 helpful/harmful。
  • 每个 semantic clause 记录 local/public observation ID、task、manifest index、signature、观测值、similarity weight 和 pooled weight。
  • compound command 若不能唯一归因到一个 semantic clause，不计入“两种 signature”gate；本次没有这种未归因 carrier。
Inference：

当前证据支持“部分 package-set overlap 有用”，但效果只有 5 个净修正且仍来自单一 repo/tool；它还不是泛化或 scheduling claim。

结论

Phase A 选择 pip Jaccard；Phase B pytest 严格 NO-GO。同 repo task repetition 确实产生可复用信号，但当前证据只覆盖 package overlap 和单文件 pytest 两个窄机制，尚不足以支持通用 semantic KB claim。
